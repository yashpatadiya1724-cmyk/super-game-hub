# Security Policy

## Reporting Security Vulnerabilities

We value security and privacy across all games and services in Super Game Hub.

To report a vulnerability or privacy concern:
- Contact the maintainer directly at: `yashpatadiya1724@gmail.com`
- Please provide details regarding the affected game module or service and reproduction steps.
- We acknowledge and review all vulnerability disclosures within 48 hours.
- Please avoid creating public GitHub issues for sensitive security vulnerabilities.
